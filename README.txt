严伟铭个人作品集 GitHub Pages 发布说明

这是纯静态网页，无需安装依赖或构建。所有路径都是相对路径，可部署为账号主页或项目主页。

1. 登录 GitHub，新建仓库。账号主页建议命名为 你的用户名.github.io；也可命名 portfolio。
2. 上传 github 文件夹内的内容到仓库根目录，包括 index.html、style.css、assets 和 .nojekyll。不要把整个 github 文件夹作为外层目录上传。
3. 仓库 Settings → Pages → Build and deployment，选择 Deploy from a branch，分支 main，目录 / (root)，保存。
4. 等待部署完成，访问 Pages 提供的网址。账号主页通常为 https://你的用户名.github.io/。

维护：修改 index.html 的内容、style.css 的样式，或替换 assets 的截图后提交即可更新。
公开站点仅含个人职业介绍、邮箱和作品截图，不包含内部项目方案、非公开业务数据或游戏源代码。
简历适合定向投递，本站暂不公开含手机号的简历附件。
